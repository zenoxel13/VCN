Опис проєкту

Наша команда з чотирьох учасників розробляє модель для прогнозування результатів футбольних матчів на основі відкритих наборів даних.

Програма аналізуватиме історичну статистику футбольних команд, щоб знаходити закономірності та визначати найбільш імовірний результат майбутнього матчу.

Мета проєкту

Створити модель, яка прогнозуватиме переможця футбольного матчу на основі статистичних показників команд.

Реалізація

Завантажити та опрацювати відкриті дані про футбольні матчі.

Визначити основні показники для прогнозування.

Перевірити точність прогнозів на тестових даних.
